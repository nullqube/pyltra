# Pyltra Vision

Version Status: Pre-v2 Canonicalization  
Document Role: Product and philosophy reference  
Stability: CONFIRMED

---

## 1. Product Identity

Pyltra is a local-first, graph-driven content runtime platform with pluggable source adapters and system-oriented execution.

Pyltra is not merely:

- a static site generator
- a build tool
- a templating wrapper

The long-term direction is a structured content runtime where filesystem is one adapter among many.

---

## 2. Product Priorities

Pyltra prioritizes:

- extensibility
- architectural coherence
- local-first workflows
- future UI support
- future AI integration
- runtime inspectability
- deterministic builds

---

## 3. Target Users

Pyltra is designed primarily for:

- developers
- technical teams
- structured content systems
- multilingual websites
- documentation systems
- hybrid local/CMS workflows

---

## 4. Local-First Philosophy

Pyltra must:

- work fully offline
- avoid cloud dependency
- preserve filesystem transparency
- preserve user ownership of content

Cloud and SaaS support may exist later, but must remain optional and additive.

---

## 5. Progressive Complexity

Pyltra should be:

```text
Simple by default
Powerful when needed
```

The framework must support both:

- convention-driven usage
- highly configurable usage

---

## 6. Explicit Non-Goals

Pyltra is not intended to be:

- a WordPress clone
- a no-code builder
- an enterprise Java-style framework
- a frontend JavaScript framework
- a React replacement
- a cloud-only platform
- a tightly opinionated filesystem-only tool
