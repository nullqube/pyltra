# Pyltra — Vision

Status: CONFIRMED

---

# Project Philosophy

Pyltra is a:

> local-first, graph-driven content runtime platform with pluggable source adapters and system-oriented execution.

Pyltra is NOT merely:

* a static site generator
* a build tool
* a templating wrapper

The long-term direction is:

> a structured content runtime where filesystem is one adapter among many.

The architecture prioritizes:

* extensibility
* architectural coherence
* local-first workflows
* future UI support
* future AI integration
* runtime inspectability
* deterministic builds

Pyltra is designed primarily for:

* developers
* technical teams
* structured content systems
* multilingual websites
* documentation systems
* hybrid local/CMS workflows

---

# Explicit Non-Goals

Pyltra is NOT intended to be:

* WordPress clone
* no-code builder
* enterprise Java framework
* frontend JS framework
* React replacement
* cloud-only platform
* tightly opinionated filesystem tool
